# Submission format

Each team is expected to make a PR to this repository, adding a <command_name> folder in `submissions`. The folder should have a following structure (for everything to work smoothly):

```
2026-oct-foundry-hackathon/submissions main*
❯ tre example-submission
example-submission
├── PRESENTATION.pdf
├── rorgt_t01.cif
├── rorgt_t02.cif
├── rorgt_t03.cif
├── rorgt_t04.cif
├── rorgt_t05.cif
├── rorgt_t06.cif
├── rorgt_t07.cif
├── rorgt_t08.cif
└── rorgt_t09.cif
```

We expect that your cif files will have names identical to those in json file provided for you (the ones in `d['queries'].keys()`).

You are also welcome to add your presentation in your team's folder -- naming doesn't matter. However, this is not obligatory.
